# bili-bcut-caption

把 SRT / LRC 字幕批量 写入/导出 必剪（Bcut）工程的桌面小工具。

## 使用方法 
1. 选择必剪数据目录: 点击“扫描目录”按钮，自动获取Bcut Drafts目录位置, 或者手动选择文件夹位置 
2. 选择必剪项目：点击单选框选择必剪项目 
3. 输入模板文本：模板文件就是提前在必剪中设置好样式的文本，后面加载的字幕都会按照这个样式生成 
4. 选择轨道层级: 这一项非必选，会自动选择
5. 选择字幕文件: 选择 SRT / LRC / ASS / SSA 格式的字幕文件
6. 加载字幕：点击”加载“按钮，完成加载，建议之前先点击”备份“
7. 导出字幕：点击“导出”按钮，选择按轨道或按模板文本导出，支持 SRT / LRC / ASS / SSA 格式
